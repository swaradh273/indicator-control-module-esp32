# Indicator Control Module – ESP32

## Description
Embedded C based indicator and hazard light control system using ESP32.

## Features
- Left & Right indicator control
- Hazard mode logic
- Button debouncing
- Timer-based LED blinking (~300 ms)

## Hardware Used
- ESP32
- Push buttons
- LEDs
- Breadboard setup
